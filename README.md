# Sagara Balinese Typeface

**Sagara Balinese** adalah *display typeface open-source* yang menggabungkan keanggunan tipografi modern dengan kekayaan warisan Aksara Bali. Didesain secara spesifik untuk kebutuhan *branding* industri *fashion* dan *beauty*, font ini menawarkan harmoni antara karakter Latin yang elegan dan proporsi Aksara Bali yang estetis.

Diinisiasi oleh **[Balibilly Design](https://www.instagram.com/balibillydesign)**, proyek ini merupakan hasil kolaborasi dengan **Ni Putu Rahayu Satriani**, desainer tipe huruf dari Institut Seni Indonesia (ISI) Denpasar, sebagai upaya melestarikan aksara lokal melalui desain kontemporer yang relevan dengan industri kreatif saat ini.

## ✨ Fitur Utama
* **Dual Script:** Mendukung penuh karakter Latin (Basic & Extended) dan Aksara Bali.
* **Display Ready:** Memiliki kontras tinggi (*high-contrast*) dan detail *glyph* yang tajam, sangat ideal untuk *headline*, logo, *editorial layout*, dan *packaging* kosmetik/fashion.
* **Open Source:** Bebas digunakan untuk proyek personal maupun komersial di bawah lisensi SIL Open Font License (OFL).

## 👁️ Type Specimen

### Latin Character Set
*Karakter Latin didesain dengan pendekatan elegan, mengutamakan lekukan yang mulus dan proporsi yang memberikan kesan mewah.*

### Balinese Script Set
*Aksara Bali disesuaikan secara visual agar dapat bersanding harmonis dengan karakter Latin tanpa menghilangkan pakem tradisionalnya.*

## 📥 Instalasi

### Untuk Pengguna Desktop (Desainer)
1. Pergi ke folder [`fonts/otf`](fonts/otf) (Direkomendasikan untuk macOS/Windows).
2. Unduh file `SagaraBalinese.otf`.
3. Klik ganda pada file yang diunduh dan pilih "Install Font".

### Untuk Kebutuhan Web (Web Developer)
Gunakan file dari folder [`fonts/webfonts`](fonts/webfonts) dan tambahkan kode berikut pada file CSS Anda:

```css
@font-face {
    font-family: 'Sagara Balinese';
    src: url('fonts/webfonts/SagaraBalinese.woff2') format('woff2'),
         url('fonts/webfonts/SagaraBalinese.woff') format('woff');
    font-weight: normal;
    font-style: normal;
}
